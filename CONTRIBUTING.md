# Contributing

1. Create a focused branch for each change.
2. Keep changes small and explain the reason in the commit message.
3. Add or update automated tests for behavior changes.
4. Run `ruff check .` and `pytest` before opening a pull request.
5. Never commit secrets or real personal financial data.
6. Update documentation when configuration, architecture or operational behavior changes.
7. Do not claim a planned integration is implemented until it has a working test and documented setup.
